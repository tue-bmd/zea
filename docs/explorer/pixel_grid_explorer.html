    Definitions
    • Frame. z = 0 is the middle of the array and +z points into the medium. Angles are measured from +z, positive toward +x.
    • zlims: depths below the transducer. The default runs to the end of the record, sound_speed · n_ax / sampling_frequency / 2.
    • xlims: the lateral extent of the grid. Cartesian grid → what the transmits insonify at zlims[1] (the same edge rays as polar_limits), and at least the probe width. Polar grid → the sector's width, and an override sets the scan-converted image's width (crop or pad). Scanline → the extent of the columns.
    • f_number: a beamforming setting, not geometry. zea's receive mask is a hard cone around each element's normal, so pixels outside every element's cone stay dark; the checks report how many. Default from the probe: 1 / (2 tan α), with α the element's −6 dB acceptance angle under zea's directivity model, sin α = 0.603 · wavelength / element_width (element width 0.9 · pitch when the file has none). Elements narrower than about 0.6 wavelength hear the whole half-space, giving 0 (no cone): typical for phased arrays. Linear arrays land near 0.5, curved arrays near 0.7.
    • grid_apex (derived, not settable): the point (x, y, z) the grid fans out from, which is where the transmits fan out from. It lies on the central axis, at or behind the array: (0, 0, −d) with d ≥ 0. It replaces distance_to_apex (= −grid_apex[2]). In order: steered transmit axes that meet in one point → that point (0 from the array middle, a virtual apex when spread over a flat array, the centre of curvature on a curved array); unsteered diverging waves → their virtual source; curved array → its radius of curvature; flat array with overridden polar_limits → the virtual apex whose sector edges pass through the array ends; otherwise 0.
    • polar_limits: the range of the transmit angles, widened on each side to cover what the transmits insonify at the deepest pixel zlims[1]. Each transmit's region is bounded by two edge rays: focused → its axis (no margin); plane wave → from the array ends along its angle (along the end elements' normals on a curved array); diverging wave → from its virtual source through the array ends. polar_margin replaces the automatic margin with a fixed angle. Scanline mode has no margin, because the columns are the transmits.
    • rlims = zlims − grid_apex[2]: radii from the apex, used by scan conversion.
    • enable_scanline: one column per focused transmit, each beamformed with its own transmit only. Steered lines whose axes meet in one point use a polar grid: the polar grid with one column per transmit angle (grid_size_x = n_tx, polar_limits = the angle range, no override), rows at rlims from grid_apex, so the columns lie on the transmit axes. Unsteered, parallel lines use a cartesian grid: a vertical column under each transmit. Anything else raises a ValueError.
    • grid_size_x of a polar grid: the outer arc length, (zlims[1] − grid_apex[2]) · (polar_limits[1] − polar_limits[0]), divided by wavelength / pixels_per_wavelength.
    • extent of a polar grid: the window the scan-converted image fills. x spans xlims; z spans the grid, but on a flat array starts at zlims[0], which crops the pixels a virtual apex places behind the array. A curved array needs no crop.
    • Radius of curvature: a probe property fitted from probe_geometry (∞ for a flat array), kept apart from the apex.
    • Missing transmits. Without transmit_origins in the file, the origins count as zeros (the middle of the array), as in the beamformer.
